# Pràctica Wireframe 2
Replica en HTML i CSS del wireframe d'un company de classe.
## Descripció
Explicacions de què són els llenguatges estotèrics, amb exemples de cadascun. Inclou imatges i enllaços sobre aquests.
## Continguts
Definició d'un llenguatge estotèric i tres exemples d'aquest: Brainfuck, Whitespace i Piet.
